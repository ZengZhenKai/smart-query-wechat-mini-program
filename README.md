# 智慧查询

基于微信小程序 + 云开发的企业内部型号查询与权限管理系统

## 项目简介

智慧查询来自实际业务场景，用于改善依赖 Excel 和人工检索型号、测试编码时效率低、权限边界不清、操作难追溯的问题。本仓库对应已完成微信好友分享能力的 1.0.5 作品集快照。

## 项目功能

- 员工注册、待审核状态，以及管理员通过、拒绝和删除员工
- `user`、`admin`、`super_admin` 三级角色与细粒度维护权限
- 总成编号和商品名称查询、多结果展示
- 测试编码、通用型号展示与一键复制
- 保密确认、用户头像和资料维护
- 型号新增、修改、删除与批量导入
- 每个型号最多 5 张图片，支持上传、查看和删除
- 操作日志与关键操作追溯
- 查询首页分享给微信好友

## 使用流程

```text
员工注册
  ↓
管理员审核
  ↓
保密确认
  ↓
进入查询
  ↓
输入总成编号或商品名称
  ↓
返回测试编码与通用型号
  ↓
复制结果
```

管理员流程：员工审核 → 型号管理 → 权限管理 → 日志查看。

## 数据结构

核心集合仅展示结构，不包含真实数据：

- `users`：用户资料、审核状态、角色和功能权限
- `models`：总成编号、商品名称、测试编码和最多 5 张图片
- `operation_logs`：操作类型、操作者、目标对象和时间

演示型号见 [`demo/models.demo.json`](demo/models.demo.json)，其中全部记录均带有 `_demo: true`。

## 权限设计

- `user`：查询、查看和复制授权数据；可按授权维护指定字段
- `admin`：员工审核、型号管理和日志查看
- `super_admin`：包含管理员能力，并可授予或取消管理员角色

敏感操作由云函数统一校验，不依赖前端按钮隐藏作为安全边界。

- 型号多字段检索、多结果展示及图片槽位管理

## 问题复盘

- 旧云环境配置导致启动失败：核对项目关联环境和客户端初始化配置。
- 注册完成未正确跳转：统一根据 session、审核状态和保密确认状态路由。
- session / 权限缓存造成超级管理员状态异常：关键管理页重新拉取服务端会话并由服务端鉴权。
- 好友分享不可用：定位到正式查询页缺少页面级分享生命周期并进行最小修复。
- 微信审核与注册流程冲突：设计可关闭、可轮换且不向客户端泄露凭据的审核通道。

## 本地运行

1. 使用微信开发者工具导入项目根目录。
2. 将 `project.config.json` 中的测试 AppID 换成自己的小程序 AppID。
3. 配置自己的云开发环境；作品集仓库中的 `miniprogram/env.js` 默认留空。
4. 在云函数环境变量中配置所需字段，字段名参考 `.env.example`。
5. 使用虚构 Demo 数据初始化测试集合，禁止混入真实公司数据。
