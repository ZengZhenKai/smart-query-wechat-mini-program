# 微信审核邀请码模式

此通道只用于微信官方审核人员进入现有查询流程。它不会修改 `models`、既有 `users`、既有 `operation_logs` 或超级管理员名单，也不会授予管理员权限。

## 云函数配置

两个配置都只能放在当前云环境的 `api` 云函数环境变量中：

- `REVIEW_MODE_ENABLED=true`
- `REVIEW_INVITE_CODE=<审核邀请码>`

不要把真实邀请码写入 `miniprogram/env.js`、WXML、源码、Git、截图或公开说明。邀请码必须为 8 至 64 位，只能包含英文字母、数字、短横线和下划线，并且区分大小写。任一配置缺失或格式无效时，服务端按关闭处理，注册请求会明确报配置错误。

开启后，未注册微信进入注册页会看到“微信审核通道”输入框。审核人员仍需填写用户名和一个未被现有账号使用、符合 `^1[3-9]\d{9}$` 的中国内地手机号。正确邀请码创建的账号固定为 `role: user`、`status: approved`，随后仍需接受保密声明；不会成为管理员或超级管理员。

邀请码原文不会写入用户或日志。用户仅保存 `reviewAccess: true` 及邀请码的 SHA-256 版本摘要，接口不会把这两个内部字段返回小程序。

## 审核结束

审核通过后立即把 `REVIEW_MODE_ENABLED` 改为 `false`（或删除），并删除或轮换 `REVIEW_INVITE_CODE`，然后重新上传部署 `api` 云函数。审核通道关闭或邀请码轮换后，曾通过该通道创建的审核账号会由云函数拒绝继续访问；普通既有用户和两个超级管理员不受影响。

## 提审备注

在微信公众平台提交审核的“版本描述/测试账号及密码/审核备注”中，说明入口路径与操作：进入小程序，填写用户名、未使用的 11 位中国内地测试手机号和本次审核邀请码，提交后确认保密声明即可进入型号查询。把云函数中 `REVIEW_INVITE_CODE` 的值原样提供给审核人员；注意大小写完全一致。
